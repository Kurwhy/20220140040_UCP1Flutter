# 📱 UCP 1 Flutter

Aplikasi mobile berbasis **Flutter** yang menampilkan fitur autentikasi pengguna serta pengelolaan data **piket**, **pelanggan**, dan **barang** melalui antarmuka yang sederhana dan terstruktur.

Proyek ini dibuat sebagai implementasi pembelajaran pengembangan aplikasi mobile menggunakan **Flutter** dan **Dart**, dengan fokus pada navigasi halaman, form input, validasi, dan penyajian data.

---

## ✨ Fitur Utama

- Login pengguna
- Register pengguna
- Halaman utama aplikasi
- Data piket
- Detail data piket
- Data pelanggan
- Detail data pelanggan
- Data barang
- Hasil data barang

---
