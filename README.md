# 📱 UCP 1 Flutter — Aplikasi Manajemen Data

**Aplikasi mobile berbasis Flutter untuk menampilkan dan mengelola antarmuka data piket, pelanggan, dan barang.**

Proyek UCP 1 Flutter merupakan aplikasi yang dikembangkan menggunakan **Flutter dan Dart** sebagai implementasi pengembangan aplikasi mobile. Aplikasi ini mencakup halaman autentikasi, halaman utama, serta berbagai halaman pengelolaan informasi.

## ✨ Fitur dan Halaman

| Halaman | Deskripsi |
|---|---|
| Login | Antarmuka masuk ke aplikasi |
| Register | Formulir pendaftaran pengguna |
| Home | Halaman utama dan navigasi aplikasi |
| Data Piket | Tampilan daftar informasi piket |
| Detail Data Piket | Informasi detail dari data piket |
| Data Pelanggan | Tampilan informasi pelanggan |
| Detail Data Pelanggan | Informasi detail pelanggan |
| Data Barang | Tampilan informasi barang |
| Hasil Data Barang | Tampilan hasil pengisian atau pengolahan data barang |

## 📱 Dokumentasi Tampilan

### 1. Login Page

Halaman login menyediakan antarmuka bagi pengguna untuk memasukkan informasi akun sebelum mengakses halaman aplikasi.

### 2. Register Page

Halaman pendaftaran menyediakan formulir untuk mengisi informasi pengguna baru.

### 3. Home Page

Halaman utama menjadi pusat navigasi untuk mengakses berbagai bagian aplikasi.

### 4. Data Piket

Halaman ini menampilkan informasi yang berkaitan dengan data piket.

### 5. Detail Data Piket

Menampilkan informasi lebih lanjut mengenai data piket yang dipilih.

### 6. Data Pelanggan

Halaman yang digunakan untuk menampilkan informasi pelanggan melalui antarmuka aplikasi.

### 7. Detail Data Pelanggan

Menampilkan detail informasi pelanggan.

### 8. Data Barang

Halaman yang menyediakan antarmuka untuk menampilkan informasi barang.

### 9. Hasil Data Barang

Menampilkan hasil informasi data barang pada aplikasi.

## 🚀 Instalasi dan Menjalankan Aplikasi

**1. Clone repository**

```bash
git clone https://github.com/Kurwhy/20220140040_UCP1Flutter.git
cd 20220140040_UCP1Flutter
```

**2. Instal dependency**

```bash
flutter pub get
```

**3. Jalankan aplikasi**

```bash
flutter run
```

Pastikan Flutter SDK dan Dart SDK yang kompatibel dengan persyaratan proyek telah terinstal.
